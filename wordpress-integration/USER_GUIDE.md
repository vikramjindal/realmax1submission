# 📖 WordPress Admin User Guide - REMAX Excellence Website

This guide explains how to update images and content for different sections of your website through WordPress Admin.

## 🚀 Quick Access
- **WordPress Admin URL**: `https://backend.joinremaxex.com/wp-admin`
- **Login**: Use your WordPress admin credentials

---

## 📍 Section 1: Homepage - Agent Carousel

**WordPress Menu**: `Agents` (in left sidebar)

**What it controls**: The rotating carousel of agent images on the homepage

**How to update**:
1. Go to **Agents** in WordPress sidebar
2. **To add new agent**:
   - Click "Add New Agent"
   - Enter agent name in the title field
   - Set "Featured Image" (this is the image that appears in carousel)
   - Set "Display Order" (lower numbers appear first)
   - Click "Publish"
3. **To edit existing agent**:
   - Click on an agent name
   - Change the Featured Image or Display Order
   - Click "Update"
4. **To delete agent**:
   - Hover over agent name → Click "Trash"

**Fields**:
- **Title**: Agent name (e.g., "John Smith")
- **Featured Image**: The carousel image (required)
- **Display Order**: Number (0, 1, 2, etc.) - lower numbers appear first

## 📍 Section 5: Marketing Page - Marketing Services (Service Cards)

**WordPress Menu**: `Marketing Services` (in left sidebar)

**What it controls**: The service cards grid in "Our Marketing Services" section on `/marketing` page

**How to update**:
1. Go to **Marketing Services** in WordPress sidebar
2. **To add new service**:
   - Click "Add New Service"
   - Enter service name in title (e.g., "Facebook Ads", "Welcome Package")
   - Set **Featured Image** (will be used if no Media URL provided)
   - Fill in:
     - **Media Type**: Choose "Image" or "Video"
     - **Media URL**: Direct URL to image/video (optional - if empty, Featured Image is used)
     - **Display Order**: Sorting number
   - Click "Publish"
3. **To edit**: Click on service → Make changes → Click "Update"
4. **To delete**: Hover → Click "Trash"

**Fields**:
- **Title**: Service name (e.g., "Facebook Ads")
- **Featured Image**: Fallback image (used if Media URL is empty)
- **Media Type**: "Image" or "Video"
- **Media URL**: Direct URL to image/video file (optional)
- **Display Order**: Sorting number

**Tips**:
- If you provide a Media URL, that will be used instead of Featured Image
- For videos, use direct video file URLs (e.g., `.mp4` files)
- For images, you can use Featured Image or provide a Media URL

## 🔄 How Changes Appear on Website

### Automatic Updates (ISR - Incremental Static Regeneration)
- Most changes appear on the website within **60 seconds** automatically
- The website rebuilds in the background when you publish/update content

### Manual Refresh (if needed)
- If changes don't appear after 2-3 minutes:
  1. Clear your browser cache
  2. Hard refresh the page (Ctrl+F5 or Cmd+Shift+R)
  3. Wait a few more minutes for the rebuild

---

## 📝 General Tips

1. **Featured Images**: Always set a Featured Image for items that need images
2. **Display Order**: Use numbers (0, 1, 2, 3...) to control the order items appear
3. **Publishing**: Click "Publish" or "Update" to save changes
4. **Draft Mode**: You can save as "Draft" to preview before publishing
5. **Deleting**: Items go to "Trash" first - you can restore them if needed

## 🆘 Troubleshooting

**Images not showing?**
- Make sure Featured Image is set
- Check that image file is not too large (recommended: under 2MB)
- Wait 1-2 minutes for changes to propagate

**Changes not appearing?**
- Clear browser cache
- Wait 2-3 minutes for automatic rebuild
- Check that item is "Published" (not Draft)

**Can't find a menu item?**
- Make sure the REMAX Integration plugin is activated
- Go to Settings → Permalinks and click "Save Changes"
- Refresh the WordPress admin page
